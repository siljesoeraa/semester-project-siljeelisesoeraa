# Fredrikstad Technical Museum 

## About the project 

This website is a semester project in Front End Development created as a website concept for a fictional museum. 

The concept is based on Fredrikstad´s industrial heritage, with a particular focus on Fredrikstad Mekaniske Verksted (FMV), shipbuilding, engineering, science, and the local community. 

The website is designed to present the museum, its exhibitions, educational programmes, family activities, facilities, and practical visitor information in a clear and accessible way. 

The target audience includes children and families with young children, in addition to school groups. 

The website is not a real museum website and is not intended for actual use. It was creadted for educational and desing purposes as part of a semester project in Front End Development.

## Design 

The design is adapted to the target audience, using a colour pallette that attracts, and a modern, clean look. The website focuses on presenting a museum and the essential information that visitors would need. 

The visual desing is inspired by Fredrikstad´s industrial and maritime history. The design aims to combine a modern museum identity with visual elements inspired by shipbuilding, machinery, engineering, and the industrial environment on Fredrikstad Mekaniske Verksted. 

The website is designed to be easy to navigate and accessible to both adults and children with focus on UX-design and responsiveness. 

## Project scope

This project focuses primarily on the design, structure, content, and user experience of a museum website. 

The website is a static concept and does not include: 
- A functioing booking system or possibilities to purchase tickets 
- A database 
- User accounts 
- Online payments 
- A conents management system 

Some links and features are therefore included as part of the website concept and design, rather than as fully functional services.
